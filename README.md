# Simple Interest Calculator

This project contains a Bash script that calculates simple interest using values entered by the user.

## Inputs
- Principal amount
- Annual interest rate as a percentage
- Time period in years

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Run
Run the following command in a Bash terminal:

bash simple-interest.sh

Enter the principal, interest rate, and time when prompted.

## Example
Principal: 1000
Rate: 5%
Time: 2 years
Simple interest: 100
